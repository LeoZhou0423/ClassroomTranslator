# 工程整改记录（2026-10-19）

## 本轮发现与修改

| 问题 | 修改与实际行为 |
| --- | --- |
| 代码压缩、命名模糊、没有统一格式 | Python/React 源码格式化；统一产品包名；提取前端类型、请求客户端、页面恢复组件；增加命名和书写规范 |
| 所有异常均返回 400 | 错误分类、正确 HTTP 状态、稳定错误码、请求编号；未预期异常不把原始异常文本发给前端 |
| 请求无限等待、断线无提示 | 请求及响应体读取均受超时约束，取消信号传递，持续断线提示和有上限退避 |
| 重复点击或重试可能重复执行 | 前端操作锁；写请求不自动重试；任务按课堂去重；录音状态冲突返回 409 |
| 设置看似保存成功 | 保存失败回滚本地设置，并保留错误提示 |
| 直接覆盖 JSON，损坏后静默回到空数据 | 原子替换、课程库有效备份、损坏库明确报错；单条损坏录音在列表中提示，不使整个列表失效 |
| 后台精修卡住、无法取消 | 显示进度和部分失败；手动发起、取消入口、旧任务中断识别；任务启动保存失败也清理注册状态 |
| 跨课堂回调及缓存影响当前内容 | generation 与条目 ID 共同标记在途请求；绑定回调变量；术语纳入缓存键；缓存限量 |
| 说话人排队和线程关闭无上限 | 队列容量限制、拥堵提示、有上限的退出等待 |
| 轮询重复、写入失败无反馈 | 删除重复历史任务轮询；模型检查降频；保存失败显示状态并保留内存内容 |

## 验证范围

新增故障注入覆盖：原子替换失败、不可序列化内容、损坏库保护、有效备份、错误隐私、磁盘满、超时、总结/精修启动失败后注册清理、取消保留进度、真实本地 HTTP 的错误契约、断网不重发、响应体超时、调用方取消和无效响应。

本地验证：205 项 Python 测试通过，6 项前端请求测试通过；Ruff 检查和格式检查、Prettier 检查、Oxlint 零警告、TypeScript strict 与 Vite 构建通过。`git diff --check` 通过。打包流程已接入检查，独立质量工作流也已加入源码；尚需提交后 GitHub 实际运行才能确认云端结果。

## 仍需后续验收与改进

- 这轮以当前共享桌面运行路径为主；`App.tsx` 和录音编排仍然较大，后续应按录音、课堂记录、设置继续拆分，在真实交互回归支撑下完成。
- TypeScript 类型检查不能替代所有外部 JSON 的运行时结构验证；供应商及本地 API 的完整 schema 校验仍可继续加强。
- 每个文件的原子写入不保证多文件事务；当前单进程桌面模型不支持多个进程同时写同一个课程库。
- 现有桌面启动日志尚需统一轮转和跨平台启动失败恢复页；本轮不把旧日志方案称为完善的可观测性系统。
- 当前凭据分发方式、服务端配额及计费保护属于后续商业化架构工作，客户端加密不等于服务端密钥保护。
- 本轮没有重新打包、上传或触发 GitHub；没有把代码构建成功当成 Windows/Mac 安装与长时间录音验收。
