# 录音启动回归检查

需要在 Mac 上构建并运行带麦克风、语音识别用途说明的应用包；Windows 无法验证 AVFoundation/Speech。

1. 固定口音：开始、说话、暂停、恢复、结束；应有字幕，每次结束后麦克风停止。
2. 自动口音：检测期间立即返回，再进入课程启动；旧检测不得在五秒后重新启动录音。
3. 启动期间返回：权限弹窗稍后同意，旧页面不得建立历史记录或启动录音。
4. 启动超时：界面显示超时并结束准备状态；底层调用未返回时再次开始应提示等待，不得重复排队启动。
5. 权限拒绝、无麦克风、识别服务不可用：显示错误，界面保持响应。
6. 连续暂停/恢复至少十次；旧任务取消回调不得中断新录音。
7. 录音和启动期间拔出 USB 麦克风、切换蓝牙设备、睡眠唤醒；应停止并提示中断，不得自动重启循环。
8. 分别在报告问题的 macOS 26、27 版本及正常版本运行以上步骤，记录精确系统版本、输入设备、口音和错误信息。若仍闪退，保留 Console 中对应 .ips 崩溃报告。

本次代码检查确认：输入节点访问仅位于音频驱动后台队列；音频回调捕获固定请求数组；停止会使旧会话回调失效；超时使旧页面启动流程失效。尚未执行 Mac 构建或设备实测。

系统音频调用如果永久阻塞，无法通过 Swift 任务取消强制终止。本次修复保持界面可响应并拒绝重复启动，底层恢复前可能需要重启应用。
